# P2P Lab1 C++

Лабораторная работа №1 - Работа с пиринговыми сетями (реализация на C++)

## Описание

Реализация двух экспериментов с микросервисами и пиринговыми сетями с использованием Boost.Asio.

### Эксперимент 1 (Микросервисы)
- **server** (порт 9000) - хранилище параметров
- **third** (порт 9002) - ретранслятор/прокси
- **client** - клиент командной строки

Цепочка: `client → third → server → third → client`

### Эксперимент 2 (Гибридный P2P)
- **tracker** (порт 9090) - центральный сервер для регистрации пиров
- **peer1** - узел P2P-сети

Функции:
- Регистрация/отмена регистрации пиров
- Обмен списками пиров
- Автоматическое обнаружение новых пиров

## Технологии
- C++20
- Boost.Asio
- CMake

## Сборка и запуск

```bash
mkdir build && cd build
cmake ..
make
```

## Эксперимент 1:
```bash
./server        # терминал 1
./third         # терминал 2
./client        # терминал 3
```
## Эксперимент 2:
```bash
./tracker 9090              # терминал 1
./peer1 9001                # терминал 2
./peer1 9002                # терминал 3
```
